# Credits

The custom artwork in `assets/` is derived from public-domain sources and original artwork.

- **Hero:** Dithered eye from the Gemini-generated blink clip (`assets/source/eye-blink.mp4`), processed by `scripts/build_assets.py`.
- **Animation:** Look-around and blink in `assets/hero.gif`, built by `scripts/build_hero_gif.py` from the same clip.
- **Astronaut:** Bruce McCandless II during EVA, STS-41-B, NASA, via [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:STS41B-35-1613_-_Bruce_McCandless_II_during_EVA_(Retouched)_(cropped).jpg). Public domain.
- **Profile card:** Layout, copy and SVG generated by `scripts/build_profile_card.py`; avatar cropped from the astronaut artwork.
- **Icons:** [Skill Icons](https://skillicons.dev) and [Simple Icons](https://simpleicons.org) (CC0).
- **Artwork processing:** Python + Pillow + ffmpeg, by this repository's `scripts/build_assets.py`, `scripts/build_hero_gif.py` and `scripts/build_profile_card.py`.
